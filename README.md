О проекте:

Это приложение предназначено для разметки изображений путем наложения сетки и присвоения ячейкам определенных классов. Оно разработано на Python с использованием PyQt5 и позволяет пользователю загружать изображения, создавать разметку, изменять размер сетки, назначать классы, редактировать их и управлять списком разметочных классов.
Основные функции

    Загрузка изображений — пользователь выбирает папку с изображениями, после чего можно просматривать и размечать каждое из них.
    Создание сетки — возможность создания сетки для разметки изображения с заданными размерами ячеек.
    Разметка ячеек — пользователь может назначать ячейкам сетки определенный класс (цвет и название).
    Редактирование классов — возможность добавления, удаления и переименования классов разметки.
    Изменение размера ячеек — функция масштабирования сетки для текущего или всех изображений.
    Выбор области — инструмент для выделения области и назначения ей класса.
    Масштабирование изображения — функции увеличения, уменьшения и сброса масштаба.
    Сохранение разметки — каждая разметка сохраняется в отдельный файл, связанный с изображением.

Как использовать

    Запуск приложения: python main.py

    Выберите папку с изображениями
        Откроется диалоговое окно, в котором нужно выбрать папку с изображениями для разметки.
    Создайте сетку
        Используйте меню "Создать сетку" и укажите размер ячеек.
    Добавьте классы разметки
        В списке классов можно добавить новый класс, указав его цвет и название.
    Размечайте изображение
        Выберите инструмент разметки и назначайте классы ячейкам.
    Сохраните результат
        Разметка автоматически сохраняется и может быть загружена при следующем открытии приложения.

Технические детали

    Язык программирования: Python
    Графический интерфейс: PyQt5
    Формат хранения разметки: Текстовые файлы (.txt) внутри подпапки grids
    Архитектура кода:
        example_app.py — главный файл с UI и логикой приложения.
        AppState.py — управляет состоянием приложения.
        ClassGrid.py, ClassGridTable.py — классы для работы с сеткой.
        Folder.py — класс для работы с загружаемыми изображениями.
        ZoomableGraphicsView.py — обработка зума изображения.
        ChangeGridSizeDialog.py, CreateGridDialog.py — диалоговые окна для работы с сеткой.
